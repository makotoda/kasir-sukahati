# Kasir Toko Sukahati

Halaman aplikasi kasir Toko Sukahati untuk GitHub Pages: https://makotoda.github.io/kasir-sukahati/

Repo ini hanya berisi hasil build (`index.html`). Datanya tersimpan di Google Sheets dan diakses lewat
Google Apps Script; kode sumbernya ada di repo terpisah. Jangan mengedit `index.html` langsung,
karena akan tertimpa saat build berikutnya.
